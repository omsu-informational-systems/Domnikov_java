## 🧠 Описание стратегии

Сервис реализует стратегию **Mean Reversion (Возврат к среднему)**. 
Она предполагает, что цена актива со временем возвращается к своему среднему значению. Сервис использует полосы Боллинджера (Bollinger Bands) для определения границ этого диапазона и индекс относительной силы (RSI) для подтверждения силы тренда. Когда цена выходит за пределы полос, а RSI показывает перекупленность или перепроданность, сервис формирует торговый сигнал.

## 🔄 Входные и выходные данные

### REST API (HTTP)
Сервис предоставляет один публичный эндпоинт для мониторинга:
*   **GET `/health`** — проверка состояния сервиса.
    *   *Возвращает:* JSON-объект со статусом (`UP` или `DEGRADED`), именем сервиса, версией и статусом внутренних компонентов.

### Входящие события (Kafka Input):
*   **`account.registration.result`** — ответ от преподавательской платформы о результатах регистрации сервиса (успех или причина отказа).
*   **`market.candle.closed`** — события о закрытии свечей с рыночными данными. Сервис получает от платформы информацию о цене открытия, закрытия, максимуме, минимуме и объеме торгов за определенный период.

### Исходящие события (Kafka Output):
*   **`account.registration.request`** — запрос на регистрацию сервиса в платформе при первом запуске (содержит `secretKey` и идентификаторы).
*   **Торговые рекомендации** — сигналы стратегии (например, `HOLD`, `BUY`, `SELL`), которые сервис публикует в ответ на анализ полученных свечей.
